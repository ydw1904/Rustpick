# Rustpick

A Rust port of [TwitchDropsMiner](https://github.com/DevilXD/TwitchDropsMiner).

Watches Twitch channels headlessly (GraphQL + websocket, no browser) to farm
drop campaign progress.

## Status

Early. Nothing works yet.

## Build

```sh
cargo run
```
